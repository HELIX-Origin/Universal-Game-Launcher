# Safety rules

- Keep changes in the assigned task's scope and avoid unrelated refactors.
- Do not commit secrets, real user library data, or credential-bearing fixtures. Metadata enrichment is optional and must remain opt-in.
- Preserve URI and executable validation, stable platform identifiers, and the separation between local scanning and official-client launch/install.
- Do not claim an integration, translation, or feature is working merely because a model or message key exists.
- Do not put private machine paths or local app data in bug reports and handoffs.
